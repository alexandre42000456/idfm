🧪 Démo - Notifications IDFM

Cette page permet de tester le système de notifications sans attendre le workflow GitHub Actions. Vous pouvez simuler différents scénarios de perturbations et voir comment les notifications se comportent.

1. Activer les notifications

Première étape: demander la permission d'afficher des notifications dans votre navigateur.

2. Tester les notifications

Une fois les permissions accordées, vous pouvez tester différents types de notifications.

3. Manipuler le fichier JSON

Pour tester avec le système réel, vous devez modifier le fichier data/disruptions.json.

📝 Instructions

  1. Ouvrir le fichier data/disruptions.json
  2. Changer "hasNewDisruptions": false en true
  3. Modifier le lastCheck avec un nouveau timestamp
  4. Sauvegarder le fichier
  5. Retourner sur index.html
  6. Attendre 30 secondes maximum
  7. Une notification devrait apparaître
{ "lastCheck": "2026-02-01T15:30:00Z", "hasNewDisruptions": true, ← Changer à true "disruptionCount": 1, "disruptions": [...] }

4. Service Worker

Vérifier que le Service Worker est correctement enregistré.

📚 Informations utiles

Console DevTools: Ouvrez la console (F12) pour voir les logs détaillés du système de notifications.
Application DevTools: Allez dans Application → Service Workers pour voir l'état du Service Worker en temps réel.
